# Executive Function Skills for Better Decisions

Decision Literacy uses journals, comparisons, predictions, reviews, and reflection. Executive function helps kids start those tools, keep track of choices, organize options, and return to decisions later.

This page is the local doorway into the Literacy for Kids [Executive Function Toolkit](https://www.literacy-for-kids.com/docs/toolkits/executive-function), connected to the clear thinking this curriculum builds.

## A few core ideas

- **Decision tools only help if you can start and use them.** A journal you never open cannot teach you anything.
- **A decision journal becomes easier with a simple checklist.** Visible steps beat holding them in your head.
- **Prioritizing helps when too many choices compete.** Not every decision needs your energy right now.
- **Reviewing later needs a reminder or restart point.** Future-you needs a bookmark.

## When this shows up

- When starting a decision journal feels like too much
- When a decision has many options
- When you need to compare pros/cons or tradeoffs
- When you need to come back later and review
- When a reflection task feels blurry

## Tools that help

- **Job clearer** — "What decision am I actually tracking?"
- **Tiny first step** — write the choice title.
- **Decision journal checklist** — the same short steps each time.
- **Must / should / could** — for sorting options.
- **Restart bookmark** — so a future review is easy to begin.

:::tip Executive Function Moment
A decision journal gets easier when the first step is tiny. Start with only the title: "The choice I'm tracking is ___." Once the page exists, the next step is easier to find.
:::

:::caution Everyday task skills, not a diagnosis
These are everyday planning and task-management tools, not therapy, medical advice, disability evaluation, ADHD treatment, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be treated as lazy or broken when starting, focusing, organizing, or finishing is hard. If tasks feel consistently overwhelming, inaccessible, unsafe, or severely distressing, involve a trusted adult and appropriate support.
:::
